A one-line fortune cookie message for a software engineer, written by a small
Node program (`main.ts`) that writes it to `/output/entry.txt`.

> You will find the bug today. It has been in production since Tuesday, and it has your name on it.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts` (Node 22+).
